# 프론트엔드 구현 및 검증 결과

2026-11-01. **백엔드 코드는 수정하지 않았습니다. 실제 서버 통합은 사용자 요청에 따라 이후 작업으로 남겼습니다.**
아래의 관리 기능은 개발 모드의 브라우저 저장소에서 동작합니다. 운영 모드는 가상 데이터 없이 연결 준비 상태를 표시합니다.

## 유지한 기존 구성

- React 19.3.1, Vite 8.3.5, TypeScript 5.9.3, Tailwind 4.3.3 설치 환경 유지. 새 라이브러리 도입 없음.
- IBM Plex Sans KR, 기존 색상·간격·모서리 토큰, 헤더, 공간 목록/좌석 요약 구성 유지.
- 의자·아이콘·범례를 `ui.tsx`로 분리하여 재사용. 기존 검색·즐겨찾기와 `seats.ts` 집계/검증 재사용.
- 기존 가상 데이터는 개발 도구에서 사용자가 명시적으로 생성하는 fixture로 격리.
- 작업 시작 전에 존재한 Figma 삭제 등 변경사항을 복원하거나 덮어쓰지 않음.

배치와 점유 상태는 서로 다른 객체로 관리합니다. 배치도는 비율 좌표의 HTML 요소이며 좌석마다 접근 가능한 이름을 제공합니다.
회전된 좌석 번호는 바르게 읽히도록 역회전합니다. 작은 모바일 개요에서는 겹치는 번호를 줄이고 확대 및 번호순 보기로 상세 정보를 확인합니다.

편집기는 드래그 중 로컬 상태만 변경하고 포인터를 놓을 때 한 번의 이력으로 저장합니다.
숫자 속성으로 드래그 없이 수정할 수 있으며, 테이블 이동은 좌석 위치에 영향을 주지 않습니다.
테이블 삭제는 좌석 연결을 해제합니다. revision 충돌과 저장 실패 시 초안을 보존하고,
최신 배치 비교·초안 다운로드·최신 배치로 다시 시작하는 복구 경로를 제공합니다.

## API 및 WebSocket

신규 실서버 API 연결은 없습니다. 실제 코드에서 확인한 것은 `GET /api/v1/health`와
빈 좌석 배열을 반환하는 `GET /api/v1/seats`뿐이며 해당 HTTP 도우미를 유지했습니다.
현재 화면에서 이 응답을 장소나 배치 데이터로 확대 해석하지 않습니다.

WebSocket 전송 모듈은 확인된 URL과 이벤트 decoder를 전달받도록 작성했습니다.
중복/과거 이벤트 무시, 버전 누락 시 재연결과 snapshot 요청, 지수 백오프와 jitter,
snapshot 제한 시간, 선택적 heartbeat, StrictMode 및 장소 전환/언마운트 정리를 지원합니다.
배치 변경 이벤트와 재연결 snapshot의 revision으로 배치를 다시 조회합니다.
소켓 연결과 센서 데이터 최신성을 분리하며, 단절/오래된/미수신 상태는 이용 가능 수에서 제외합니다.
이 동작은 단위 테스트와 개발 이벤트로 검증했으며 실제 FastAPI WebSocket과 연결한 것은 아닙니다.

실제 서버 계약 조사와 연결 체크리스트는 [INTEGRATION.md](INTEGRATION.md)에 있습니다.

## 검증 중 수정한 문제

- 개발 모듈의 HMR 재로딩 시 이벤트가 다른 모듈 인스턴스에 갇히는 문제를 창 이벤트로 해결.
- Ctrl+S가 편집 중인 숫자 입력값을 저장하지 않던 문제를 blur/상태 반영 후 저장하도록 수정.
- 재연결 중 놓친 배치 변경을 snapshot revision과 REST 배치 revision 비교로 복구.
- 회전 좌석 번호가 뒤집히던 표시, 모바일 좌석 번호 겹침, 모바일 공간 선택 버튼 배치 수정.
- 모바일 관리자 표에서 정보가 가려지는 문제를 세로 목록으로 보완. 태블릿은 첫 열 고정 및 키보드 스크롤 제공.
- 운영 번들에 개발 로그인 안내 문자열이 남는 문제를 빌드 분기로 제거하고 빌드 검사 추가.

## 남은 범위

실제 서버 인증/관리자 접근 제어, 장소·배치·장치 API, 삭제/충돌 정책, 장치 토큰,
WebSocket 메시지 및 이용률/감지 유효 기간의 서버 기준 매핑이 필요합니다.
하드웨어 수신과 실제 서버 재시작 후 영속성/unknown 초기화는 검증하지 않았습니다.
개발 저장소 초기화 검증을 실제 서버 재시작 검증으로 간주하지 않습니다.
모바일 편집기는 속성 입력과 스크롤을 제공하지만 복잡한 배치 편집은 데스크톱을 우선합니다.

실행 방법과 개발 계정은 [README.md](README.md)를 참고하세요.
